3가상 데이터 설계에 쓰는 법

실제 데이터에서 구조와 비율을 가져오면, 생성기가 "대충 만든 랜덤 데이터"가 아니라 근거 있는 시뮬레이션이 됩니다.

로그 스키마

GDMC 2017 구조를 따름

로그 하나에 공통(유형·시각·위치), 행위자(ID·레벨·종족), 대상물(아이템·등급·수량·스킬), 대상(대상 ID·골드·받은 피해) 4개 그룹. 행동은 82개 유형을 6개 분류(접속·캐릭터·아이템·스킬·퀘스트·길드)로 묶음.

봇 행동

"자기 유사성"

봇은 같은 행동을 반복해서 행동 패턴이 스스로와 닮아 갑니다. 2인 파티, 평균보다 긴 접속, 경험치 로그는 많고 종족 포인트 로그는 적은 패턴도 보고됐습니다.

헷갈리는 집단

헤비 유저 ≠ 봇

오래 플레이하고 빠르게 성장하는 헤비 유저가 봇으로 오탐되기 쉽습니다. "헤비 유저"를 별도 집단으로 나누자 오탐이 881건에서 327건으로 줄었습니다. 생성기에도 헤비 유저를 꼭 넣어야 합니다.

4대회 출제자들이 남긴 교훈

  • 데이터 오류는 피할 수 없었습니다. 엔씨소프트는 2017·2018·2019년 대회 모두 데이터 공개 후 오류가 발견돼 다시 추출했습니다. 2019년 참가자들은 대회 중간에 "fishing 변수 오류, 전투·비전투 시간 집계 오류" 공지를 받고 전처리를 처음부터 다시 했습니다. 출제팀은 "데이터 분석에도 단위 테스트 같은 소프트웨어 공학 기법이 필요하다"고 결론 내렸습니다.
  • 재현성이 평가 항목이 됐습니다. 2018년에는 대부분의 팀 코드를 재현할 수 없었습니다. 그래서 2019년부터 코드 제출 형식을 정하고 재현 여부를 점수(25점 만점)에 반영했습니다. 우리 파이프라인도 Docker로 누구나 다시 돌릴 수 있게 만들어야 합니다.
  • 시간이 지나면 패턴이 바뀝니다. 업데이트와 사업 모델 변경으로 유저 행동이 바뀌어, 학습 시점과 다른 시기의 데이터에서는 성능이 크게 떨어졌습니다. 패치로 스키마가 바뀌는 상황을 오염 유형에 넣은 것도 같은 이유입니다.
  • 점수 차이 1~2%보다 실전 적용이 중요합니다. 모델 수십 개를 조합한 팀보다 PC에서 15분이면 학습되는 가벼운 모델이 실무에는 더 유용해 보였다고 평가했습니다.
  • "성능이 제일 좋아서"는 설명이 아닙니다. 본선에서 가장 많이 지적된 점이 기법 선택 이유를 성능으로만 설명한 것이었습니다.

5이용할 때 주의할 점

  • 원본 재배포 금지: 신청해서 받은 데이터는 GitHub 저장소에 올리지 않습니다. 저장소에는 다운로드 방법과 출처만 적습니다.
  • 인용 요청: HCRL은 관련 논문 3편(SpringerPlus 2016, IEEE TIFS 2016, NDSS 2016)을, OpenDota는 프로젝트 인용을 요청합니다. 발표 자료와 README에 출처를 표기합니다.
  • 신청은 일찍: HCRL 데이터는 이메일 승인이 필요하고 응답 시점을 알 수 없습니다. 프로젝트 1주차에 신청합니다.
  • OSRS API 규칙: python-requests, curl 같은 기본 User-Agent는 차단됩니다. "LogWatchdog-student-project - 연락처" 같은 설명형 User-Agent를 쓰고, 아이템별로 반복 호출하지 말고 전체를 한 번에 받습니다.
  • IEEE DataPort: 다운로드에 로그인과 구독이 필요합니다. 학교나 기관 구독이 있는지 먼저 확인합니다.

6확인하지 못한 것

  • GDMC 2017 데이터의 구글 그룹 다운로드 링크가 지금도 살아 있는지는 확인하지 못했습니다. 논문에는 공개됐다고 적혀 있지만, 홈페이지에는 직접 링크가 없습니다.
  • HCRL 데이터의 이용 조건(라이선스)은 페이지에 적혀 있지 않습니다. 받을 때 함께 확인해야 합니다.
  • Kaggle Data Science Bowl 2019 데이터의 컬럼 구성은 이번에 원문에서 확인하지 못했습니다.
  • IEEE DataPort 게임봇 데이터(88일)는 페이지에 게임 이름이 없습니다. 같은 연구실의 논문(B-4)이 아이온 88일 데이터를 쓰지만 인원수가 조금 달라서(49,530명 vs 49,739명) 같은 데이터인지 단정할 수 없습니다. HCRL 챌린지 데이터(22일)와는 기간이 달라 서로 다른 데이터입니다.
